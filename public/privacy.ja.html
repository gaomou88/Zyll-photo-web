プライバシーポリシー

施行日：2026 年 11 月 8 日

要点：私たちはあなたの情報を一切収集しません。収集することもできません。

サーバーはありません

Zyll フォト Web 版は GitHub Pages で公開している静的な Web サイトです。あなたのブラウザ上で動作し、あなた自身の Google ドライブや OneDrive に直接接続します。写真、ファイル名、アカウント情報、パスワードが Zyll のサーバーを経由することはありません。そもそもサーバーがないからです。

データの保存場所

  • 写真とバックアップの目録は、あなた自身のクラウドに保存され、あなたが管理します。
  • ログイントークンと一部の設定（自動ロックの時間など）は、いま使っているブラウザのローカルストレージにだけ保存されます。アカウントの接続を解除するか、ブラウザのデータを消去すると削除されます。
  • 暗号化された写真は、あなたのブラウザ内でだけ復号されます。パスワードが保存されたり、どこかに送信されたりすることはありません。

第三者

ログインやクラウドの読み書きのリクエストは、Google または Microsoft に直接送られます。Web サイトを開くときのリクエストは GitHub が処理します。これらの企業はそれぞれのプライバシーポリシーに従ってリクエストを処理し、Zyll がそのデータを見ることはできません。

この Web サイトはアクセス解析、広告、トラッキングのコードを一切使用していません。

変更

このポリシーを変更する場合は、このページの内容と施行日を更新します。
