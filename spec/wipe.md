# 删除全部备份数据与“已清空”标记 `vault/wiped.json`

用户可以在 App 的“我的 › 备份”里删除所有已登录网盘账号里的 Zyll 备份（照片、缩略图、备份目录、密钥包、共享相册、AI 整理结果），
从头开始。别的设备（另一台手机、网页版）当时不一定在线，所以删除的设备要在每个账号里留一个标记，
别的设备看到后停止往这个账号写，不把删掉的数据传回去。

## 1. 标记

```json
{ "format": "zyll-wiped", "version": 1, "at": 1762800000000, "device": "<写它的设备 id>" }
```

- 路径和密钥包同一个文件夹：`vault/wiped.json`，放在库当前所在的位置（Google 可见文件夹里的库就写在可见文件夹）。
- 明文，不加密：删除以后本机已经没有密钥了，别的设备也要在没解锁时就能读到。
- 删完以后**保留**，和 Google 隐藏区的 `storage.json` 一样不删。以后重新开始备份时也不删。
- 搬存储位置时当作固定名字的文件，原样覆盖过去。

## 2. 删除的设备

1. 记下要删的账号和这次的时间 `at`（写到磁盘），关掉自动备份；中途停下时下次接着删，删完之前不往网盘写任何东西。
2. 暂停共享相册的推送（排着的取消，正在推的等它停下），之后共享相册的所有写操作都拒绝。
3. 先在每个账号写标记，再列文件、删文件（标记本身不删）。
4. 删完一个账号后再列一遍，把标记写下之前就开始的上传（旧版本、刚好在传的）也删掉。
5. 这个账号本机的记录和缓存清掉，记下“见过”的 `at`。
6. 所有账号都删完，最后才删本机的密钥和共享相册列表：中途停下时，剩下的加密文件还能用本机密钥和网盘上的密钥包解开。

## 3. 别的设备

每个设备按账号记一个“见过的 `at`”（App 按账号标识记，换账号不串；网页按浏览器记）。

**App**：每轮备份开头、传目录和密钥包之前、一轮里传很久时每隔几分钟，读一次标记。
- 没有标记、或者 `at` 不比见过的新：照常。
- `device` 是自己，或者这台手机从没往这个账号传过东西（没有记录、密钥包也没传过）：记下见过，照常。
- 否则就是别的设备删除过：
  - 删掉自己在 `at` 前 24 小时以内传上去的文件（那边列文件时可能还没有，没删到）；
  - 清掉本机这个账号的记录和缓存，记下见过的 `at`；
  - 这个账号停着，不再往里写（备份、目录、密钥包、共享相册、改信息、重建目录都不写），直到用户在这台手机上点“重新开始备份”，
    或者重新打开自动备份，才当作空账号从头开始；
  - 如果已经没有别的账号可以备份，本机的密钥、共享相册列表也清掉，关掉自动备份（和删除的那台一样，旧密码从此作废）；
  - 提醒用户一次。
- 读不到标记（断网）时这一轮先不碰这个账号。

**网页**：打开页面加载账号时读一次标记。
- 比这个浏览器见过的新：本机没写进目录的上传、删除和见过的目录序号都作废（否则会把它们写回空账号，或者把新库当成“被还原过”），
  有这些东西时提醒用户；记下见过的 `at`。
- 之后每次写网盘（提交目录、上传、删除、写密钥包、共享相册）之前再读一次：比打开页面时新，就把账号改成只读、提示刷新页面。

## 4. 旧版本

不认识这个标记的旧版本 App 和网页会照常往里写，把照片、目录和密钥包传回去。删除前的确认框要提醒：
其他设备先更新到新版本，或者先在那边断开。
